Algorithmic Pipeline

How TextTrace Works

A four-stage deterministic data pipeline transforming raw unformatted inputs into structured comparative telemetry.

1 STAGE_INPUT

Add Documents

Paste raw text directly or upload clean UTF-8 encoded .txt files into designated Document A and B workspaces.

File buffer reading • Char validation
2 STAGE_NORM

Process Text

Tokenization, lowercase normalization, punctuation stripping, and configurable stop-word filtering for syntactic consistency.

RegEx token extraction • Filter pass
3 STAGE_HASH

Find Matches

Rabin–Karp rolling hash substring matching identifies exact phrase subsequences alongside token-level frequency set intersection.

Polynomial hash • Collision check
4 STAGE_DIFF

Review Results

Examine the circular similarity metric, token frequency breakdown, and interactive highlighted reading view side-by-side.

Score telemetry • Visual report
