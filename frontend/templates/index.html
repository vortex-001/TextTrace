Algorithm Reference for Viva

1. Rabin-Karp Rolling Hash

Word hashes use multiplier 31. Sliding window of k words uses base B = 131 and prime M = 1,000,000,007. Sliding update: h_new = ((h_old - leading) * B + incoming) % M. Time: O(N + M) average.

2. Merge Sort

Passages are sorted longest first using custom stable recursive merge sort without built-in sorted(). Time complexity: O(P log P).

3. HashMap & HashSet

Document vocabulary frequency is mapped using Python dict (HashMap) and unique words in set (HashSet) for O(1) average lookups.

4. Longest Common Subsequence

Dynamic programming matrix computes exact word-level LCS order if documents have ≤ 2,000 words. Complexity: O(N × M) time and space.

Notice: TextTrace detects exact word sequences using algorithmic hashing. Quotations and common terminology are matched as well. A high score indicates textual similarity, not necessarily intentional plagiarism.
